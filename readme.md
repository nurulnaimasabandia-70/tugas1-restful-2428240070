## Deskripsi

Project ini merupakan RESTful API sederhana untuk mengelola data sepatu.
API dibuat menggunakan Node.js dan Express.js dengan data yang disimpan
sementara dalam array (in-memory).

## teknologi

- Node.js
- Express.js
- Nodemon
- Postman
